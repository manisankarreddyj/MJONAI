Install on Android

← dashboard

Same Wi-Fi as this machine: open http://<machine-ip>:8787 in Chrome, then:

  1. Chrome menu (⋮) → Add to Home screen → Install.
  2. Launch MJONAI from your home screen — standalone window, no browser chrome.

Remote access requires the server started with MJONAI_APP_HOST=0.0.0.0 and MJONAI_APP_TOKEN set; open http://<machine-ip>:8787/#token=YOUR_TOKEN once — the page remembers it locally and signs every API call.

The app is read-only. It cannot place orders.

On this machine: just open http://127.0.0.1:8787 in Chrome and use Add to Home screen the same way.
