## P0 — Money-Path / Safety / "Lose-or-Hide-Money" Findings
*(Critical: capital protection, fail-closed gates, anything that can lose money)*

### Kill Line — Session + Lifetime Circuits (REPAIRED 2026-09-20)
- **Claim**: "Kill line arms in any non-RESEARCH mode (LIVE+PAPER), implements session circuit (>=15% drawdown from session peak anchored to yesterday's close) AND lifetime circuit (equity <=85% of persisted watermark, monotonic, manual-reset only)"
- **Reality**: `emergency_triggers.py:538-576` computes BOTH session circuit (drawdown from session peak anchored to yesterday's close) AND lifetime circuit (equity <=85% of `load_peak_equity` watermark). Previously only armed in LIVE; 2026-09-20 owner ruling extended to PAPER too. RESEARCH never reads/advances watermark.
- **Evidence**: `emergency_triggers.py:556-566` — `load_peak_equity()` persists peak via `save_peak_equity()`; `get_current_drawdown_pct()` measures session drawdown. Regression pins: `test_kill_line_arms_in_paper_mode`, `test_kill_line_does_not_arm_in_research_mode`, `test_lifetime_ruin_circuit_fires_even_when_session_is_flat`.
- **Severity**: P0 — if broken, unchecked drawdown could lose capital.

### Max 2% Risk Per Trade Caps (VERIFIED)
- **Claim**: "INTRADAY=1.0%, SWING=1.5%, POSITIONAL=2.0% risk caps, anchored to static TOTAL_CAPITAL, not live equity"
- **Reality**: `STRATEGY_RISK_POLICIES` in `constants.py:405-428` defines `risk_pct_capital=0.010/0.015/0.020`. `calculate_position_size()` in `trade_risk.py:406-439` applies these caps LIVE. RESEARCH mode uses fixed `PAPER_POSITION_SIZE_RESEARCH` at `trade_risk.py:397-403`.
- **Severity**: P0 — broken caps could exceed intended risk limits.

### SEBI 10-OPS Token Bucket Limiter (VERIFIED)
- **Claim**: "10 OPS max, 10 burst limit; LIMIT-only order types; registered algo_tag on every dispatch; timeout → fail-closed refusal + ledger row release/keep"
- **Reality**: `algo_execution.py:21-53` defines `SEBIRateLimiter(max_ops=10, burst_limit=10)`. `GLOBAL_RATE_LIMITER` singleton acquired before every broker slice in `orders.py:247`; timeout means legal limit would be exceeded → dispatch refused, reserved row released (reason `SEBI_RATE_LIMIT` if no slice sent yet, `KEPT` if earlier slices already reached broker).
- **Severity**: P0 — OPS violation could enable overtrading.

### Psychology Guard — 45m VIX-Scaled Symbol Lock on STOP_LOSS_HIT (VERIFIED)
- **Claim**: "2 losses on same symbol → 45-minute symbol freeze; VIX scaling: sym_mins = int(round(45 * (1.2 if current_vix > 20 else 1.0))"
- **Reality**: `behavioral_guard.py:307` — `SYMBOL_COOLDOWN_MINUTES=45` with VIX scaling. `is_symbol_locked()` check in `pipeline.py:372-373` enforces lock. 3-stage escalation: 2 losses→30m pause, 3→60m, 4→full day lockout. EOD terminal after 02:30 PM IST.
- **Severity**: P1 — if broken, same-symbol overtrading risk.

### T+1 Settlement — Same-Calendar-Date Round Trips Settle INTRADAY (VERIFIED)
- **Claim**: "SHORT settles INTRADAY (0.025% STT sell-only, no DP); same-date LONG round trips settle under INTRADAY"
- **Reality**: `trade_risk.py:689-690` — "SHORT swing settles INTRADAY (0.025% STT sell-only, no DP)". `processor.py:234-239` — "same-date LONG round trips settle under INTRADAY here too". `test_costs.py:147-149` confirms.
- **Severity**: P2 — mis-settling could affect cost calculations but not directly lose money.

### Per-Tranche Rollup Into Parent P&L (VERIFIED)
- **Claim**: "Per-tranche P&L rolls into parent settlement without double-counting"
- **Reality**: `eod.py:607-608` — `tranche_pnl = get_closed_tranche_pnl(str(trade_id)) or {}` then `gross_pnl = round(gross_pnl + float(tranche_pnl.get("gross_pnl", 0.0)), 2)`. `tracker.py:220-226` and `orders.py:607-608` same pattern. No double-counting.
- **Severity**: P2 — accounting error but not capital loss.

### FII/DII Honest Contract — No Fabricated Zeros (VERIFIED, REPAIRED 2026-09-20)
- **Claim**: "FII/DII stub returns explicit no-feed sentinel (feed_available=False) instead of fabricated all-zero readings"
- **Reality**: `fetch_fii_dii_cash_flow` was rewritten to return `feed_available=False` sentinel (zero values, empty date_str) when no live feed. Previously an overrides-only injector that fabricated `date_str=today` all-zero readings. Now `_build_fii_dii_factor` gates on `feed_available`; `is_fii_heavy_selling` and `fii_dii_flow` require `feed_available` so sentinel leaks no signal.
- **Severity**: P1 — fake FII/DII data could mislead regime flags.

### Cross-Regime Fallback Refused (VERIFIED, FIXED 2026-09-18)
- **Claim**: "`AngelOneIntradayProvider` now fails closed on non-`SMART_API` provenance tag instead of silently mixing yfinance-adjusted bars under RAW cache key"
- **Reality**: Provider now reads fetcher's provenance stamp (`df.attrs["data_provider"]`) and **fails closed** on any explicit non-`SMART_API` tag. Previously silently fell back to yfinance `auto_adjust=True` (ADJUSTED regime), corrupting every absolute-price indicator read back from RAW cache.
- **Severity**: P1 — mixed-regime data could produce false signals.

### Validate OHLCV DataFrame Rejects Bad Data (VERIFIED, FIXED 2026-09-18)
- **Claim**: "`validate_ohlcv_dataframe` rejects entirely-empty required column and non-finite/non-positive decision-bar value"
- **Reality**: Function exists and rejects empty required columns and non-finite/non-positive values in the decision bar (5 regression tests). Previously a corrupt candle could become a signal.
- **Severity**: P2 — data integrity guard.

### Fail-Closed Behavior Throughout (VERIFIED)
- **Claim**: "Stale feeds → None; broker unavailable → cancel reserved row; rate limit timeout → refuse; missing algo tag → config error at startup"
- **Reality**: Multiple fail-closed patterns: `is_token_fresh` probe (`tracker._get_current_price`, pipeline entry resolution, `close_all_paper_trades`) gates every raw-dict read and fail closes on stale/unknown tick; `SEBI_RATE_LIMIT` cancel + row release; `close_all_paper_trades` scoped to `system_mode=SYSTEM_MODE` only (not cross-mode); rate limiter timeout → `cancel_trade(reason="SEBI_RATE_LIMIT")` if no slices dispatched yet.
- **Severity**: P1 — fail-open anywhere could fabricate trades or move money.

### Kill-Line Auto-Close All Positions on 15% Drawdown (VERIFIED, REPAIRED 2026-09-03)
- **Claim**: "`_fire_kill_line()` calls `close_all_paper_trades(exit_reason="KILL_LINE")` to close all positions"
- **Reality**: Fixed 2026-09-03: old code had TypeError because `close_all_paper_trades(exit_reason=...)` doesn't accept keyword arg; fixed by passing as positional arg. `test_kill_line_arms_in_paper_mode` regression pin confirms.
- **Severity**: P0 — if broken, 15% drawdown wouldn't liquidate positions.

### Close-All-Paper-Trades Mode-Scoping (VERIFIED, REPAIRED 2026-09-03)
- **Claim**: "Queries unfiltered → closes positions across RESEARCH/PAPER/LIVE at once"
- **Reality**: Fixed 2026-09-03: now uses `get_open_trades(system_mode=SYSTEM_MODE)` — one mode only. Previously one mode's Kill Line would liquidate ALL books at once.
- **Severity**: P1 — cross-mode contamination.

### SEBI Algo Enforcement — 10-OPS + LIMIT-Only + Registered Algo_Tag (VERIFIED, REPAIRED 2026-09-17)
- **Claim**: "Every live dispatch carries `algo_tag=SEBI_ALGO_TAG` and `order_type="LIMIT"`; rate limiter acquired before every slice"
- **Reality**: `orders.py:287` — `algo_tag=SEBI_ALGO_TAG` on every live dispatch. `orders.py:285` — `order_type="LIMIT"` (SEBI prohibits MARKET/IOC). `validate_execution_config()` in `order_guards.py:176-182` fails if `SEBI_ALGO_TAG` is placeholder/default. `tests/test_orders.py:424-426` asserts `algo_tag` checked.
- **Severity**: P0 — bypass could enable unauthorized order types.

### T+1 Settlement Math Verified (VERIFIED)
- **Claim**: "Same-calendar-date equity trades settle as INTRADAY (0.025% STT, no DP) — not DELIVERY"
- **Reality**: `trade_risk.py:689-690` confirmed. `processor.py:234-239` confirmed. `test_costs.py:147-149` test confirms. Bilaterial 0.10% STT + DP applies only to DELIVERY.
- **Severity**: P2 — cost accounting accuracy.
